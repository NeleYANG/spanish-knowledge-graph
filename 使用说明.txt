【西班牙语知识图谱 · 分享版】

两个版本并存：
- index.html + styles.css + app.js —— 原「星际」版（线上正在跑的）
- index-paper.html + paper.css + app-paper.js —— 新「纸墨」版（教材纸底 + 红笔 + ascii 变位表扉页），
  交互、数据、功能与原版完全一致，只是换了一层皮；无 hash 打开即为正常体验。

打开方式（二选一）：
1. 双击 index.html — 直接在浏览器打开（需联网加载 3D 引擎，推荐 Chrome/Edge）
2. 如双击后数据不显示，在该文件夹打开终端运行：
   npx serve .   或   python3 -m http.server 8080
   然后浏览器访问显示的地址

功能说明：
- 顶部搜索框：输入中文知识点名称（如「虚拟式」「过去未完成时」「冠词」），下拉会列出候选
- 点选候选知识点 → 3D 图谱自动聚焦该节点，高亮显示：
  · 纸墨版：红色实线 = 必要先修（选中某点时），墨色细线 = 常规先修关系
  · 右侧面板依次列出「所属知识模块（含同模块其他知识点）」「所属课时」「直接先修」「可解锁主题」「掌握证据」
- 节点颜色 = CEFR 等级，十级十色，分三段：
    暖色 A1.1–A2.2（姜黄 → 琥珀 → 陶橙 → 砖红）
    冷色 B1.1–B2.2（松绿 → 孔雀蓝 → 靛蓝 → 群青）
    紫色 C1.1–C1.2（紫罗兰 → 酒紫）
  底部等级轴上那条色带就是完整图例，十段与十个刻度一一对齐。
- 搜索：输入知识点名称（中文或西语原名均可）出现候选，↑↓ 选择、回车或点击定位；
  若该知识点高于当前等级轴上限，会自动把标尺抬到那一级再定位
- 鼠标悬停节点：弹出纸片卡片，显示知识点名、所属领域与模块、CEFR 等级（带等级色块）、模块点数
- 鼠标悬停节点：弹出纸片卡片，显示知识点名、所属领域与模块、CEFR 等级（带等级色块）、模块点数
- 底部等级轴：A1.1 到 C1.2，拖动可按欧标等级过滤显示
- 左下「知识领域」：语音 / 词汇 / 语法 / 功能 / 话题 / 篇章 / 策略 / 文化 八类可单独开关
- 右上「知识结构」：打开二级模块目录（8 个领域 › 38 个知识模块 › 264 个知识点）
  · 每个模块标出中文名、西语名、一句话说明、包含几个知识点、覆盖哪几级 CEFR
  · 点任一模块 → 图谱只留这一块，方便「一次只学一块」
  · 面板里「全部展开」可一次看到全部 38 个模块
- 「自动演示」按钮：自动播放知识体系的成长过程

数据：《现代西班牙语》学生用书 1–6 册 · A1–C1 · 264 个知识点 · 38 个知识模块 · 262 条先修关系 · 96 课时

需要留意：
语法条目按教材目录核对过，但「哪一条落在哪一课」的逐条对位仍需对照实体教材复核。
这份图谱是结构梳理，不是官方教学大纲。
