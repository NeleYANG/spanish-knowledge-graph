# 西班牙语知识图谱

基于 Three.js + 3d-force-graph 的 3D 力导向知识图谱，把《现代西班牙语》学生用书 1–6 册拆成**原子知识点**，用有向图呈现「先修 → 解锁」的学习路径。覆盖 **A1.1 – C1.2** 共 10 个等级档。

页面视觉以**圣家堂剪影**为封面，配色取自西班牙的材料色：墨黑褐 `#08060A`（夜里的老街）、暖金 `#F0B429`（黄昏落在石灰岩上的光）、石榴红 `#AC3F4C`（granada＝石榴城，也是弗拉门戈的红）、石灰岩 `#D8C7AC`。

> 封面为什么是纯剪影：手绘线稿（描边 + 肋线 + 球饰）细节密度会超过几何精度，看起来像栅栏。剪影只要守住四件事就能被认出是圣家堂——塔细长、四塔成组且组间留大空隙、塔身中段有一道凸台、塔顶收成针尖再顶十字。

### 知识点配色：三家族，不是八个独立色

八个领域各配一个高饱和色，等于八个「主角」同台，色相互相打架。改按**知识的性质**归三个家族：

| 家族 | 领域 | 色相 | 逻辑 |
| --- | --- | --- | --- |
| 形式 · Forma | 语音 / 词汇 / 语法 | 暖金 → 深赭（同色相逐级加深） | 语言本身的材料：发音、词、结构 |
| 运用 · Uso | 功能 / 话题 / 篇章 | 海青 → 靛蓝（同色相） | 把语言拿去办事：交际、主题、读写 |
| 语境 · Contexto | 策略 / 文化 | 赤陶 → 石榴红 | 学习方法与文化背景 |

规则：**家族内色相相邻＝相关；跨家族色相拉开 100° 以上＝不相关**。同一领域内再按 CEFR 等级微调明度（入口偏亮、最高级压暗），语法那 150 个节点因此有明暗梯度，不再是死板一片。左下角图例按三族分行，配色规则一眼可对。

### 二级知识模块：领域（8）› 模块（38）› 知识点（264）

只有七个领域时，「语法」一个框里塞 165 个点，等于让人自己翻目录——看不出「时态是一条线」「从句是另一条线」。所以加了一层**模块**：一个模块 = 一个可教、可学、可测的教学板块，通常对应教材 2–4 课的核心语法 / 功能块。模块内部有点的先后，模块之间有真实先修边。

**这一版还顺手做了三次领域改判**（因为原来的归类与学习方式不符）：

- 「议论文结构、摘要、文学细读、翻译取舍」这类原来记在**功能**名下，和「打电话、问诊」混在一起。前者靠篇章分析，后者靠情景操练 → 独立出**篇章**领域（33 点）
- **语法**里的语篇/语用条目（修辞格、叙事视角、主位推进、语用预设、语域）→ 并入**篇章**
- A2/B1/B2/C1 四份「语法自测清单」本质是复习动作 → 并入**策略 › 复习与自测**

完整的 38 个模块见 `data/quality-report-spanish.json` 的 `moduleBreakdown`，或直接点页面右上「知识结构」。

## 功能特性

- **三维力导向图谱**：264 个知识点节点按先修关系自动布局，颜色区分 8 个知识领域
- **知识结构面板**：右上「知识结构」按钮打开「领域 › 模块 › 知识点」目录，38 个模块逐条列出中文名、西语名、一句话说明与点数；点任一模块即把图谱收窄到这一块
- **所属模块**：详情面板 01 区显示该点属于哪个模块、模块共几个点，并把同模块的其他知识点排成一行（当前点高亮），一眼看出「这一块我学到哪了」
- **悬浮信息卡**：鼠标停在节点上显示「名称 / 领域 › 模块 / 等级 / 模块点数」，跟随光标并自动避让屏幕边缘
- **搜索定位**：顶部搜索框输入中文知识点名，候选下拉实时联想（带「领域 › 模块」），选中后镜头聚焦并高亮
- **先修 / 解锁双向追溯**：右侧面板列出「所属模块」「所属课时」「直接先修」「可解锁主题」「掌握证据」
- **CEFR 等级轴**：底部 A1.1 → C1.2 十档滑块，拖动即按等级裁剪图谱范围
- **自动生长动画**：一键播放知识体系随等级逐步点亮的成长过程
- **自动演示**：沿重点知识链路播放动画，逐步展示学习路径
- **领域筛选**：语音 / 词汇 / 语法 / 功能 / 话题 / 篇章 / 策略 / 文化 八类自由开关，按「形式 / 运用 / 语境」三族分行
- **关系图例**：必要先修、建议先修、课时关联、教材顺序四类边线分色显示

## 数据来源

教材结构来自《现代西班牙语》学生用书 1–6 册（董燕生、刘建，外语教学与研究出版社），每册 16 课，共 96 课。

| 教材分册 | 对应等级 | 课时数 | 目录核对情况 |
| --- | --- | --- | --- |
| 第 1 册 | A1.1 – A1.2 | 16 | 已核对 UNIDAD 1–7 五节结构；UNIDAD 8 / 9 / 16 语法条目已确认 |
| 第 2 册 | A2.1 – A2.2 | 16 | 已核对 UNIDAD 1–4 语法条目 |
| 第 3 册 | B1.1 – B1.2 | 16 | 已核对册数与等级（图书馆元数据：共 16 课） |
| 第 4 册 | B2.1 – B2.2 | 16 | 已核对册数与等级（图书馆元数据：共 16 课） |
| 第 5 册 | C1.1 | 16 | 已核对（新版学生用书 5 共 16 课，本科三年级用） |
| 第 6 册 | C1.2 | 16 | 已核对（第 6 册目录 16 Lecciones） |

**必须说清楚的一点**：教材的语法条目已按目录核对，但「哪一条落在哪一课」的逐条对位，仍需对照实体教材复核。这份图谱是结构梳理，不是官方教学大纲。`data/quality-report-spanish.json` 的 `verification` 字段逐项记录了核对状态。

图谱结构已通过完整性校验：无环、无孤立点、无自环、无重边、无悬空端点、无逆序边；先修图根节点 53 个、叶节点 109 个；渲染图（先修 + 课时关联 + 教材顺序）单连通、无孤立节点。核心度 Top3：「主格人称代词」1.000、「ser 的陈述式现在时变位」0.982、「第一变位 -ar 动词现在时规则变位」0.836。

## 快速开始

```bash
node serve.cjs                      # http://localhost:3211
python3 -m http.server 3211         # 或任选静态服务器
```

渲染依赖通过 CDN 加载（three@0.160.0 + 3d-force-graph@1.73.3），无需 `npm install`，首次打开需联网。

## 项目结构

```
.
├── index.html                       # 页面骨架（圣家堂开场 / 搜索 / 等级轴 / 详情面板）
├── app.js                           # 可视化主程序（渲染、交互、搜索、演示、动画）
├── styles.css                       # 深空 + 红金主题样式
├── taxonomy-data-spanish.js         # 西语数据（264 知识点 / 262 先修关系）
├── serve.cjs                        # 本地静态服务器
├── 使用说明.txt                      # 面向使用者的简要说明
├── assets/                          # 静态资源
├── data/
│   └── quality-report-spanish.json  # 数据质量与图健康报告
└── scripts/
    ├── data_syllabus_es.py          # 知识点源数据（6 册 96 课 + 先修关系）
    ├── build_spanish_data.py        # 构建 → taxonomy-data-spanish.js + 质量报告
    ├── apply_spanish_shell.py       # 一次性：把德语骨架改造为西语外壳
    ├── rebuild_cover.py             # 生成圣家堂剪影 SVG（可重复执行）
    └── stamp_assets.py              # 按内容哈希给静态资源打 ?v= 版本号
```

## 构建流程

```bash
python3 scripts/build_spanish_data.py   # 生成数据 + 质量报告
python3 scripts/rebuild_cover.py        # 需要改封面几何时执行
python3 scripts/stamp_assets.py         # 改完 js/css 后必须执行，否则浏览器读旧缓存
```

## 数据结构

`taxonomy-data-spanish.js` 挂载全局变量 `MARBLE_DATA_SPANISH`，包含 8 个顶层字段：

| 字段 | 说明 |
| --- | --- |
| `topics` | 264 个原子知识点（id / 类型 / 领域 / 中文名 / 西语名 / 描述 / 掌握证据 / 评估提示 / CEFR 依据 / 中心度） |
| `dependencies` | 262 条先修关系，`strength` 为 `hard`（概念级必要先修）或 `soft`（同概念跨课时进阶） |
| `lessonRecords` | 96 条课时记录，负责教材位置与顺序 |
| `topicMetadata` | 知识点到课时、教材章节的归属与拆分方式 |
| `lessonTopicLinks` | 课时与知识点的归属关系，用于生成课时关联边 |
| `curriculumSequence` | 95 条教材课时编排顺序边（不是知识先修关系） |
| `concepts` | 96 个概念组，按课时主题聚合 |
| `quality` | 数据质量统计与图谱健康度 |
